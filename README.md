# Recall

A mobile-first flashcard revision app built with plain HTML, CSS and JavaScript.

## Deploy to Netlify

1. Extract the ZIP.
2. Open Netlify and choose Add new site → Deploy manually.
3. Drag the `recall-netlify` folder onto the deploy area.
4. Open the generated site URL on your phone and add it to your home screen if you want an app-like shortcut.

No build command or environment variables are needed.

## Storage

Cards are saved in the browser's local storage on the device where you use the app. Use Export backup regularly. Import that JSON backup on another device to move your cards.

## Importing cards

Open Import, paste JSON generated using the built-in prompt, preview it, and add it to a deck. The app does not connect to an AI API or read PDFs directly.
